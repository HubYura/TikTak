# Перевірка з дитиною (15 хвилин)

Мета — побачити, де дитина застрягає, а не перевірити, чи вона «вміє».

## Перед початком
- Батьківське меню → «Почати з нуля», щоб прогрес був чистий.
- Звук і голос Тіка увімкнені. Телефон або планшет — так, як дитина гратиме насправді.
- Нічого не пояснюйте. Скажіть лише: «Це гра про годинник. Спробуй».

## Дивіться й записуйте
| Хвилина | Що дивитись | Позначка |
|---|---|---|
| 0–2 | Чи знайшла кнопки «Урок» / «Гра» сама? Чи дивилась відео Тіка до кінця? | |
| 2–6 | Чи розуміє, яка стрілка коротка, а яка довга? Чи тягне стрілку пальцем без підказки? | |
| 6–10 | На яких питаннях помиляється? (Запишіть час на годиннику й відповідь дитини.) | |
| 10–13 | Чи натискає «Не знаю»? Чи слухає пояснення після помилки, чи одразу тисне «Далі»? | |
| 13–15 | «Що тут найцікавіше? А що нудне?» | |

## Сигнали, що щось не так
- Дитина читає питання довше 10 секунд або просить прочитати вголос → текст задовгий.
- Натискає навмання, щоб швидше → питання нудні або заважкі.
- Не помічає, що Тік показує на годинник → жести замалі.
- Говорить «не зрозумів», коли говорить Тік → погана озвучка (запишіть фразу).

## Після
Перешліть нотатки й, якщо можна, 1–2 фрази, які дитина сказала сама. Найцінніше — дослівні слова й місця, де вона завмирала.
